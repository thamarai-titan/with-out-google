# Beyond Google

A curated, privacy-first directory of the best independent alternatives to everyday Google products. Built with a focus on minimal design, speed, and user experience.

🌐 **Live Demo:** [nogoogle.ilotus.dev](https://nogoogle.ilotus.dev)

---

## ⚡ Features

* **Privacy-First Focus:** Highlights open-source and tracking-free software.
* **Minimalist UI:** Clean, text-forward interface inspired by premium design systems.
* **Categorized Directory:** Seamlessly organized by Google product (Search, Drive, Mail, etc.).
* **Lightning Fast:** Statically generated and optimized with Next.js.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Typography:** Epilogue (via `next/font/google`)
* **Deployment:** Vercel
